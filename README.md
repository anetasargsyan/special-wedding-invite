# Wedding invitation

Copy the entire contents of this folder into the root of your GitHub repository, including the hidden `.nojekyll` file. Commit and push, then enable **Settings → Pages → Deploy from a branch → main → / (root)**.

`index.html` is the homepage. Keep `4_files` alongside it. No build step is required.

The countdown targets November 6, 2026 at 00:00 Yerevan time (UTC+4), stored as epoch milliseconds `1793908800000`.

The page requests no search indexing through a robots meta tag and robots.txt. These requests are voluntary: a public repository and its Pages site remain publicly accessible, even with a random name.

Some original vendor scripts, fonts, and service integrations may still contact external services.
